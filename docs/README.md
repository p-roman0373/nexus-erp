## Objetivo del proyecto:

Desarrollar un prototipo de ERP que permita gestionar los módulos de Inventario y CRM, aplicando Scrum para entregar incrementos funcionales, con trazabilidad completa entre historias de usuario, diseño en Figma, diagramas en PlantUML y control de versiones en GitHub. El proyecto busca que los estudiantes practiquen planificación, ejecución, revisión y documentación de software siguiendo buenas prácticas ágiles.

## Alcance del proyecto:

- Módulo Inventario: registro de productos, control de stock, movimientos de entrada y salida, alertas de stock mínimo.¿
- Modulo CRM: registro y gestión de clientes, seguimiento de interacciones y reportes de actividad.
- Diseño UX/UI: prototipos navegables en Figma para validar la experiencia de usuario.
- Arquitectura: diagramas de componentes, secuencias y clases con PlantUML.
- Gestión y trazabilidad: historias de usuario en CSV, tablero Kanban en GitHub Projects, commits y PRs vinculados a cada historia, definición de DoR/DoD.

## Propósito:

Entregar un proyecto demostrable que muestre la capacidad de aplicar Scrum, modelado visual, desarrollo incremental y documentación de trazabilidad, permitiendo entregar un valor tangible al usuario final y demostrar aprendizajes técnicos y de gestión de proyectos.
